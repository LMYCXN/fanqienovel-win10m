# 番茄小说 · Windows 10 Mobile

## 项目简介

一款面向 Windows 10 Mobile 的番茄小说阅读器，让 Lumia 手机也能搜索书籍、查看目录和在线阅读小说。

- 支持按书名、作者搜索书籍，加载更多搜索结果。
- 查看书籍简介，按章节目录选择阅读位置。
- 支持上一章、下一章、字号调整和夜间模式。
- 自动保存最近阅读的书籍与章节，下次打开可以继续阅读。

当前提供 **ARM 手机安装包**，已在 Lumia 950（Windows 10 Mobile 10.0.15254.603）上验证。阅读需要联网，目前没有离线下载和独立书架功能。

## 下载安装说明

### 下载

前往 [GitHub Releases](https://github.com/LMYCXN/fanqienovel-win10m/releases)，在最新版本的 **Assets（附件）** 中下载文件名以 `_ARM.zip` 结尾的安装包，例如：

```text
FanqieReader_0.4.0.0_ARM.zip
```

安装使用 ARM 安装包即可；`Source.zip`、`Source code (zip)` 和 `Source code (tar.gz)` 是源码，供开发者使用。

### 首次安装

1. **开启开发者模式**：在手机中打开「设置 → 更新和安全 → 开发者选项」，选择「开发者模式」并确认。
2. **解压安装包**：将解压后的文件放到手机存储中，例如「下载」文件夹。也可以先在电脑上解压，再通过 USB 复制到手机。
3. **安装依赖**：用手机的「文件资源管理器」打开 `Dependencies/ARM` 文件夹，依次点击其中的三个 `.appx` 文件并确认安装。
4. **安装证书**：点击 `FanqieReaderDev.cer`，在证书页面选择「安装」，完成后点击「确定」。
5. **安装主程序**：点击 `FanqieReader_版本号_ARM.appx`，确认安装。
6. **打开应用**：在手机应用列表中找到「番茄小说」并打开。

证书用于让手机信任本程序的开发者签名，依赖包用于提供程序运行所需的组件。

### 更新版本

下载并解压新版安装包，直接安装新版主程序 `.appx`。证书和依赖没有变化时，通常无需重复安装。

保留旧应用直接更新，可以保留阅读进度和设置；卸载应用会清除这些本地数据。

如果点击安装后应用没有出现，先检查开发者模式是否开启，以及证书和三个 ARM 依赖是否已经安装。

## 程序使用说明

### 搜索书籍

在首页输入书名或作者，点击「搜索」，再点击结果中的书籍进入详情与目录。结果列表底部出现「加载更多」时，可以继续获取搜索结果。

### 查看简介与目录

简介默认显示四行，点击「展开简介」查看全文，点击「收起简介」恢复。简介和章节列表可以一起上下滚动。

目录每页显示 100 章，可以使用底部的「上一页」「下一页」，或通过章节范围下拉框跳到指定页。点击章节标题开始阅读。

### 阅读与外观设置

- 上下滑动正文阅读当前章节。
- 点击底部「上一章」「下一章」切换章节。
- 点击「目录」返回当前章节所在的目录页。
- 点击「A−」「A+」缩小或放大字号。
- 使用顶部的「夜间模式」开关切换明暗外观。
- 手机系统返回键按「正文 → 目录 → 书籍列表」逐级返回；目录页也可以点击「返回书籍」。

### 继续阅读

程序自动保存最近一次成功打开的书籍和章节。下次启动后，点击首页「继续上次阅读」即可恢复。

阅读进度保存到章节，不记录章内滚动位置；字号和夜间模式设置也会保留。

### 加载提示

加载时可以点击「取消加载」。如果页面显示「操作失败」，可根据提示检查网络并重试。

正文顶部会显示章节完整性状态；出现「片段或完整性未确认」时，表示当前返回的正文可能不完整。
